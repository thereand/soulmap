| 项目 | 要求 |
|------|------|
| **推荐工具** | Midjourney V6 / 即梦AI / Stable Diffusion / 文心一格 / DALL-E 3 |
| **统一风格** | 神秘星空幻想风（Celestial Fantasy），半身角色立绘 |

## 1.4 批量生成的效率技巧

1. **先定风格锚点**：先生成 1 张（推荐从 INFJ 或 ENFP 开始，光效最出彩），确定满意的风格后，把该图的风格作为参考（Midjourney 用 `--sref` 或图生图），保证 16 张一致性。
2. **固定种子**：SD 用户可固定 seed 值，只改角色描述部分。
3. **元素分组**：按元素批量做（火系 5 个、光系 3 个、土系 3 个、水系 2 个、风系 2 个、暗系 1 个），同元素配色相近，更容易统一。
4. **稀有度差异**：SSR 3 张加强光效和粒子密度，R 级适当简化，形成视觉层级。

# 第二部分：12 种付费报告文案生成方案

## 2.1 需要补全的类型

以下 12 种类型目前在 `src/data/results/paid-reports.ts` 中为**简化占位版**，需要补全为完整内容：

`INTP` `ENTJ` `ENTP` `INFJ` `ENFJ` `ISFJ` `ESTJ` `ESFJ` `ISTP` `ISFP` `ESTP` `ESFP`

> 已完整的 4 种（INTJ / INFP / ENFP / ISTJ）作为**质量标杆**，新内容需达到同等水准。

## 2.2 报告结构要求（严格对齐代码接口）

每份报告必须包含以下 7 个字段（对应 `PaidReport` 接口）：

| 字段 | 中文含义 | 字数要求 | 语气 |
|------|---------|---------|------|
| `deepAnalysis` | 深度性格分析 | **约 500 字**，分 4 段 | 深刻、有洞察、让人"被看穿"的震撼感 |
| `innerWorld` | 内心世界描述 | **约 300 字**，分 2 段 | 私密、细腻、触及内心柔软处 |
| `socialStyle` | 社交风格 | **约 200 字**，1 段 | 具体、有画面感 |
| `loveStyle` | 恋爱风格 | **约 200 字**，1 段 | 结尾点明"你需要的伴侣是..." |
| `careerAdvice` | 职业建议 | **约 200 字**，1 段 | 具体到行业/岗位 + 避坑建议 |
| `growthPath` | 成长建议 | **约 200 字**，1 段 | 温柔而有力的成长课题 |
| `famousPeople` | 同类型名人 | **3-5 个**，中外结合 | 真实知名人物 |

## 2.3 文案核心原则（决定付费转化率）

1. **共鸣感 > 准确性**：让用户读完觉得"这说的就是我"，产生情感共鸣。
2. **具体 > 笼统**：用具体场景代替抽象形容（"朋友搬家时第一个到场帮忙的人"胜过"你很热心"）。
3. **正向 + 建设性**：即使谈弱点，也用成长视角包装，不让用户感到被否定。
4. **文学性**：多用比喻、意象（星海、火焰、档案馆），契合"灵魂星图"品牌调性。
5. **第二人称"你"**：全程用"你"直接对话，增强代入感。

# 第三部分：生成后的资源接入步骤

## 3.1 接入角色插画

1. 将生成的 16 张图命名为对应类型代码：`INTJ.png` `INTP.png` ... `ESFP.png`
2. 图片压缩优化（推荐用 [TinyPNG](https://tinypng.com) 压到 100KB 以内/张）
3. 放入目录：`src/static/images/spirits/`
4. **小程序主包体积限制**：如果 16 张图总和超过 1.5MB，改为上传到**微信云存储**，
   在代码中通过云存储 URL 引用（自带 CDN 加速），避免撑爆主包。
5. 在 `src/data/results/types.ts` 中为每个类型添加 `avatar` 字段（需先扩展接口）：
   ```typescript
   // 本地引用
   avatar: '/static/images/spirits/INTJ.png'
   // 或云存储引用
   avatar: 'cloud://your-env.xxxx/spirits/INTJ.png'
   ```

## 3.2 接入付费报告文案

1. 把大模型生成的 JSON 内容，逐个替换 `src/data/results/paid-reports.ts` 中对应的
   `XXXX_PAID` 常量（如 `INTP_PAID`、`ENTJ_PAID` 等占位版本）。
2. 注意保持 TypeScript 格式：多段文本用 `+` 拼接并保留 `\n\n`，例如：
   ```typescript
   deepAnalysis:
     '第一段内容...\n\n'
     + '第二段内容...\n\n'
     + '第三段内容...\n\n'
     + '第四段内容...',
   ```
3. 删除文件顶部第 5 行和第 113-115 行的 TODO 注释。
4. 替换完成后运行 `npm run build:h5` 验证无语法错误。
