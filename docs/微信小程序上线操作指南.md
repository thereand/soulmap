# 微信小程序上线操作指南（个人/无营业执照版）

> 适用于：无营业执照的个人开发者
> 项目：灵魂星图（SoulMap）性格测试应用

---

## 整体策略

由于没有营业执照，**无法直接开通微信支付**。推荐采用以下策略：

| 阶段 | 方案 | 目的 |
|------|------|------|
| 第一阶段 | 个人主体小程序 + 云开发 + H5版本 | 验证产品市场契合度（PMF） |
| 第二阶段 | 注册个体工商户 → 升级为企业主体 | 开通支付，正式商业化 |

**关键认知**：个体工商户≠需要门面店铺，可以零成本在线注册（电子营业执照），最快1-3天下证。

---

## 第一阶段：快速上线验证（1-2天）

### Step 1：注册个人主体小程序

1. 打开浏览器访问 **https://mp.weixin.qq.com**
2. 点击右上角 **"立即注册"**
3. 选择账号类型：**"小程序"**
4. 填写注册信息：
   - 邮箱：填写一个**未注册过微信公众平台**的邮箱
   - 密码：设置登录密码
   - 点击注册，进入邮箱完成验证
5. 选择主体类型：**"个人"**
6. 填写个人信息：
   - 管理员姓名（真实姓名）
   - 管理员身份证号
   - 管理员微信扫码验证
7. 注册完成，进入小程序后台

**获取 AppID：**
- 左侧菜单 → "开发管理" → "开发设置" → 复制 **AppID**

> ⚠️ 个人主体限制：不支持微信支付、不支持"心理咨询"类目
> ✅ 可以做的：发布小程序、使用云开发、社交分享

---

### Step 2：开通微信云开发

1. **下载微信开发者工具**
   - 访问 https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
   - 下载 Windows 64 版本，安装

2. **导入项目**
   - 打开开发者工具 → "导入项目"
   - 目录选择：`f:\工作项目\性格测试app\soulmap`
   - AppID 填入上一步获取的 AppID
   - 点击"导入"

3. **开通云开发**
   - 点击工具栏 **"云开发"** 按钮
   - 首次使用会提示开通，点击"开通"
   - 计费模式选择：**"按量计费"**（新用户每月有免费额度）
   - 环境名称填：`soulmap-prod`
   - 等待环境创建完成（约1-2分钟）
   - **记录环境 ID**（格式如：`soulmap-prod-1g2h3j4k`）

4. **创建数据库集合**
   - 在云开发控制台 → 点击 **"数据库"** 标签
   - 点击 "+" 创建集合，依次创建：

   | 集合名称 | 权限设置 | 用途 |
   |---------|---------|------|
   | `users` | 仅创建者可读写 | 用户信息 |
   | `test_results` | 仅创建者可读写 | 测试结果 |
   | `orders` | 仅管理端可读写 | 订单记录（预留） |

5. **上传云函数**
   - 在开发者工具左侧文件树中，展开 `cloudfunctions` 目录
   - 右键每个云函数文件夹 → **"上传并部署：云端安装依赖"**
   - 依次部署：`login`、`submitResult`、`getReport`、`shareToken`
   - （`createOrder` 和 `payCallback` 暂不部署，等开通支付后再部署）

6. **配置项目环境 ID**
   - 打开 `src/services/cloud.ts`
   - 找到 `wx.cloud.init` 调用，填入你的环境 ID：
   ```typescript
   wx.cloud.init({ env: '你的环境ID' })
   ```

---

### Step 3：配置并发布小程序

1. **修改应用配置**
   - 打开 `src/manifest.json`，修改 `mp-weixin` 节点：
   ```json
   "mp-weixin": {
     "appid": "你的AppID",
     "setting": {
       "urlCheck": false
     }
   }
   ```

2. **修改小程序类目**（重要！）
   - 小程序后台 → "设置" → "基本设置" → "服务类目"
   - 选择：**"工具 > 信息查询"** 或 **"教育 > 在线视频课程"**
   - ❌ 不要选"医疗/心理咨询"相关类目

3. **第一阶段收费替代方案**
   - 由于无法开通微信支付，修改付费墙策略为：
     - 方案A：**观看激励广告解锁**（接入微信小程序广告，个人主体支持）
     - 方案B：**分享3人解锁**（纯裂变模式，验证传播力）
     - 方案C：**引导加微信群/公众号，手动发报告**（验证付费意愿）
   - 推荐先用**方案B**验证产品吸引力

4. **编译并上传**
   - 开发者工具 → 点击 **"上传"** 按钮
   - 填写版本号：`1.0.0`
   - 填写描述：`灵魂星图 - 趣味性格探索`

5. **提交审核**
   - 小程序后台 → "版本管理" → 找到开发版本
   - 点击 **"提交审核"**
   - 审核通常 1-3 天通过

6. **同步部署 H5 版本**
   - 运行 `npm run build:h5`
   - 将 `dist/build/h5` 目录部署到任意静态托管平台：
     - 推荐：腾讯云静态网站托管（云开发免费额度内）
     - 或：Vercel / Netlify / GitHub Pages
   - H5版本无需审核，可立即通过链接分享

## 第二阶段：注册个体工商户开通支付（3-7天）

### Step 4：在线注册个体工商户

> 💡 2024年起，全国大部分地区支持**全程网上办理**，无需到现场

1. **选择注册方式**（任选其一）：

   | 方式 | 平台 | 耗时 | 费用 |
   |------|------|------|------|
   | 自己注册 | 各地市场监管局官网/小程序 | 1-3天 | 免费 |
   | 代办 | 支付宝/微信搜"个体工商户注册" | 1-5天 | 0-200元 |

2. **自行注册步骤**（以"电子营业执照"小程序为例）：
   - 微信搜索 **"电子营业执照"** 小程序
   - 或访问当地市场监督管理局网站（如：https://amr.sz.gov.cn）
   - 选择 "个体工商户设立登记"
   - 填写信息：
     - **字号名称**：如"XX市XX信息咨询服务部"（XX为你的名字/地区）
     - **经营场所**：填你的家庭住址即可（大部分地区允许住宅）
     - **经营范围**：选择 "信息技术服务" "软件开发" "互联网信息服务"
     - **经营者**：你本人
   - 上传身份证照片
   - 电子签名
   - 提交后等待审批（通常1-3个工作日）

3. **获取电子营业执照**
   - 审批通过后，在"电子营业执照"小程序中下载
   - 截图/导出 PDF 备用

---

### Step 5：开通银行对公账户（可选）

> 个体工商户可以使用**法人个人银行卡**作为结算账户，不强制要求对公账户

- 如果选择用个人银行卡：跳过此步骤
- 如果需要对公账户：携带营业执照去银行开户（建议选招商/建设银行，手续简单）

---

### Step 6：小程序主体升级

1. 登录小程序后台 https://mp.weixin.qq.com
2. "设置" → "基本设置" → "主体信息" → **"主体类型升级"**
3. 选择 **"个体工商户"**
4. 上传营业执照照片
5. 填写经营者信息（与执照一致）
6. 法人微信扫码验证
7. 等待审核（1-2天）

> 升级后 AppID 不变，已发布的小程序不受影响

---

### Step 7：申请微信支付商户号

1. 访问 **https://pay.weixin.qq.com**
2. 点击 **"成为商家"** → 注册商户号
3. 填写资料：

   | 项目 | 填写内容 |
   |------|---------|
   | 商户类型 | 个体工商户 |
   | 营业执照 | 上传电子营业执照照片 |
   | 法人身份证 | 正反面照片 |
   | 结算账户 | 法人个人银行卡号（或对公账户） |
   | 经营类目 | **"IT科技 - 软件/建站/技术开发"** |
   | 商户简称 | 灵魂星图 |
   | 客服电话 | 你的手机号 |

4. 提交后等待审核（1-5个工作日）
5. 审核通过 → 获得**商户号（Mch ID）**

---

### Step 8：关联支付并配置

1. **关联小程序与商户号**
   - 登录商户平台 pay.weixin.qq.com
   - "产品中心" → 开通 **"JSAPI支付"**
   - "AppID授权管理" → 输入你的小程序 AppID → 发起关联
   - 登录小程序后台确认关联请求

2. **设置 API 密钥**
   - 商户平台 → "账户中心" → "API安全"
   - 设置 **APIv3 密钥**（自定义32位字符串，妥善保存）
   - 申请并下载 **API证书**（apiclient_cert.pem）

3. **配置到云函数**
   - 云开发控制台 → "设置" → "环境变量"
   - 添加以下环境变量：
   ```
   MCH_ID = 你的商户号
   MCH_API_KEY = 你的APIv3密钥
   ```
   - 或直接修改 `cloudfunctions/createOrder/index.js` 中的配置

4. **部署支付相关云函数**
   - 在开发者工具中右键 `cloudfunctions/createOrder` → "上传并部署"
   - 右键 `cloudfunctions/payCallback` → "上传并部署"

5. **测试支付流程**
   - 使用微信开发者工具的"真机调试"功能
   - 完成测试 → 点击付费按钮 → 确认支付弹窗正常出现
   - 使用小额（0.01元）测试实际支付

## 完整时间线

```
Day 1  ┃ 注册个人小程序 + 开通云开发 + 部署H5版本
       ┃ 同时：开始注册个体工商户（线上提交）
       ┃
Day 2  ┃ 提交小程序审核（个人主体版，无支付）
       ┃ H5版本上线，开始小范围测试传播效果
       ┃

       ┃ 个体工商户营业执照下发
       ┃
Day 5  ┃ 小程序主体升级为个体工商户
       ┃ 提交微信支付商户号申请
       ┃
Day 6-10┃ 等待支付审核（期间持续运营、积累用户）
       ┃
Day 11 ┃ 支付审核通过 → 配置密钥 → 部署支付云函数
       ┃ 更新小程序：裂变模式 → 正式付费模式
       ┃ 提交新版本审核
       ┃
Day 13 ┃ ✅ 完整版上线（含支付功能）
```

## 注意事项

1. **小程序名称**：建议起名"灵魂星图"或"星灵探索"，避免"MBTI""心理测试"等词
2. **隐私协议**：小程序审核要求有隐私协议，在小程序后台 → "设置" → "隐私协议" 中配置
3. **个体工商户经营范围**：一定要包含"信息技术服务"或"软件开发"
4. **支付费率**：微信支付默认费率 0.6%（即收100元扣0.6元手续费）
5. **结算周期**：T+1 自动结算到银行卡
6. **第一阶段验证指标**：
   - 测试完成率 > 70%（说明体验OK）
   - 分享率 > 30%（说明有传播力）
   - 如果以上达标，立即推进第二阶段开通支付

## 常见问题

**Q：个人主体能发布性格测试小程序吗？**
A：可以，但要注意类目选择。选"工具-信息查询"，避免选医疗/心理相关类目。

**Q：没有营业执照能收费吗？**
A：不能直接通过微信支付收费，但可以通过广告变现（激励广告）或引导到第三方平台。

**Q：个体工商户会有税务负担吗？**
A：月营业额10万以下免征增值税；年利润低于100万的部分，个税税率仅5%。

**Q：注册个体工商户需要租店铺吗？**
A：不需要，大部分地区允许用住宅地址注册，选择"住所"类型即可。

**Q：小程序升级主体后需要重新审核吗？**
A：已发布的版本不受影响，新版本提交时按新主体审核。
